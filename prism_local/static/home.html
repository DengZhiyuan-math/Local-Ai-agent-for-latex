Claude account

Before each message, the agent panel checks that Claude Code is logged in to this account with its subscription. If it is another account, or an API key would be billed (ANTHROPIC_API_KEY, apiKeyHelper, …), nothing is sent. A profile folder lets the editor use another login than claude in your terminal: log in once with CLAUDE_CONFIG_DIR=<folder> claude.

GitHub

Every project gets a repository of its own, separate from the prism-local repository. It is created with the GitHub CLI (gh), using the account it is logged in to.
