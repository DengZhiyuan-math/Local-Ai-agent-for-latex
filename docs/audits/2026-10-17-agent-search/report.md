## 限制

- 这一轮占用 agent。聊天面板里 agent 正在回答时不能发起，反过来也一样，两边都会用一句话说明。
- 规则是 JavaScript 正则，嵌套很深的括号（例如 `\frac{…{…}…}` 整体换写法）可能写不成规则；这种情况下 agent 会改为逐处列出修改，数量多时回答会很长。
- 提议里的说明按原文显示，其中的 `$i$` 不渲染成公式；总结会渲染。
- 方案里的"请 agent 复核选中的几处"没有做。
