## 与方案不同之处

- **查找时不再用 `searchcursor.js`。** 匹配全部由 `findlogic.js` 在整个文本上算出，再换算成位置。这样，单个文件的查找、全项目搜索和替换，用的是同一个正则和同一套整词规则。
- **字数的命令参数表比方案里列的多**，例如 `\setlength`、`\textcolor`、`\hypersetup`、`\addbibresource`。`\\[2pt]` 的 `[2pt]` 不算字。
- **窄窗口（≤ 800 px）时侧栏原本完全隐藏**，全项目搜索会在看不见的地方打开。现在搜索时侧栏照样显示。这是截图时发现的。
- **编辑器很窄时，查找栏的按钮会换行**，不再溢出到侧栏上。这也是截图时发现的。

## 执行中的发现

- 在 Windows 的 Git Bash 里，heredoc 中的 `\\` 被吞成了 `\`，有几处字符串因此出错（`"\n"` 变成了真换行）。都已当场发现并改正，`node --check` 和测试均通过。之后含反斜杠的修改都改用编辑工具来做。
- 本机 9333 端口被另一个会话的 Chrome 占着，没有去动它。浏览器测试在导出的副本上改用 9561 端口，测试内容不变。
